==================================================
مستندات پروژه Block-118 (نسخه 1.0)
==================================================

۱. نمای کلی پروژه
پروژه Block-118 یک وب‌اپلیکیشن مدیریت ساختمان است که برای یک ساختمان ۱۰ طبقه با ۴۰ واحد (هر طبقه ۴ واحد) طراحی شده است. این پروژه در محیط Termux روی اندروید توسعه یافته و در حال حاضر روی Vercel آنلاین است.

۲. پشته فناوری (Tech Stack)
- Frontend: React.js + Vite + Tailwind CSS + فونت وزیرمتن (راست‌چین)
- Backend: Node.js + Express (متوقف شده)
- Database: Firebase (Firestore) - در حال اتصال
- Hosting: Vercel
- Version Control: Git & GitHub (Tech-quantum/Block-118)
- Environment: Termux (Android)

۳. تاریخچه اقدامات انجام شده (Timeline)

فاز ۱: راه‌اندازی و اسکلت‌بندی
- نصب پیش‌نیازها در Termux (git, gh, nano).
- ساخت ریپوی گیت‌هاب با نام Block-118.
- ایجاد ساختار Monorepo (پوشه‌های client و server).
- ساخت فایل‌های اولیه تنظیمات.

فاز ۲: بک‌اند و دیتابیس (متوقف شده)
- نصب پکیج‌های Express, Mongoose, Dotenv.
- طراحی مدل‌های Mongoose (Building, Unit, User, Charge).
- تلاش برای راه‌اندازی MongoDB محلی (با خطای Unknown Platform مواجه شد).
- تغییر مسیر به سمت Firebase.
- مواجهه با خطای PERMISSION_DENIED (IAM) در بک‌اند.

فاز ۳: توسعه فرانت‌اند (در حال انجام)
- نصب پکیج‌های React, Vite, Tailwind CSS, PostCSS.
- تنظیم فایل‌های کانفیگ و اضافه کردن فونت فارسی وزیرمتن.
- طراحی صفحات با استفاده از داده‌های تستی (Mock Data): داشبورد، منوی پایین، شارژها، درخواست‌ها، مودال جزئیات و صفحه ورود (Login).

فاز ۴: استقرار (Deployment)
- اتصال ریپوی گیت‌هاب به Vercel.
- تنظیم Root Directory روی پوشه client.
- استقرار موفقیت‌آمیز و دریافت لینک دائمی: block-118.vercel.app

۴. چالش‌ها و راه‌حل‌ها
- مشکل پکیج mongodb-memory-server: تغییر دیتابیس به Firebase.
- مشکل به‌هم‌ریختگی کدها در Termux: استفاده از پیست دستی یا پایتون به جای cat.
- خطای Git Push Rejected: تنظیم git config pull.rebase false و اجرای git pull.
- مشکل خطای IAM فایربیس: اتصال مستقیم فرانت‌اند به فایربیس با Client SDK.

۵. وضعیت فعلی
- اپلیکیشن ریسپانسیو است.
- ورود با نام کاربری admin و رمز 1234.
- اطلاعات فعلی به صورت Mock در فایل App.jsx قرار دارند.

۶. مراحل بعدی
- اتصال به Firebase (فرانت‌اند).
- حذف داده‌های تستی و خواندن از Firestore.
- ساخت پنل ادمین برای تعریف یوزر و پسورد ساکنین.
- تبدیل به PWA.

۷. نکات امنیتی مهم
- فایل serviceAccountKey.json هرگز کامیت نشود.
- قوانین Firestore فعلاً برای تست باز است و باید محدود شود.
